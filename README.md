# 💰 Sistema Bancário em Python

Este projeto é um sistema bancário simples desenvolvido em Python, com o objetivo de praticar lógica de programação e simular operações financeiras básicas.

## 🚀 Funcionalidades

- Ver saldo
- Depositar dinheiro
- Sacar dinheiro
- Visualizar extrato
- Simular investimentos com juros
- Sistema de "porquinho" com ganho diário
- Saque de valores do porquinho

## 🛠️ Tecnologias utilizadas

- Python
